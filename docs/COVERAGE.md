# Code coverage report (JaCoCo)

The HTML report is **generated by Maven**. Create it on your machine (Windows PowerShell):

```powershell
.\mvnw.cmd clean verify
```

Then open **`docs\jacoco\index.html`** in a browser and commit the `docs/jacoco/` folder.

| Command | Result |
|---------|--------|
| `.\mvnw.cmd test` | runs the tests and writes the HTML report to `docs/jacoco/` |
| `.\mvnw.cmd verify` | same, and **fails the build if line coverage is below 60%** (rule in `pom.xml`) |

About Docker: one test class (`DatabaseMigrationIntegrationTest`) starts a real MySQL 8 with Testcontainers. If Docker Desktop is
**running**, it runs and also covers more code. If Docker is not running it is **skipped** (shown as skipped, not failed) and the other
tests must still reach 60%.

Take a screenshot of the report's first page (table with "Lines" / "Cov.") and save it as `docs/screenshots/jacoco-summary.png`.

If coverage is below 60%, open the report, click a package and look at the red lines. Add tests for behaviour that matters
(rules, errors, security), not for getters.
